# وب‌سایت رضا پودینه | دیجیتال مارکتینگ

قالب استاتیک، فارسی و راست‌چین برای معرفی خدمات دیجیتال مارکتینگ؛ ساخته‌شده با HTML، CSS و JavaScript خالص و بدون فریم‌ورک یا وابستگی اجرایی.

## اجرا
کافی است فایل `index.html` را در مرورگر باز کنید. برای توسعه محلی می‌توانید از افزونه Live Server در VS Code استفاده کنید.

## انتشار روی GitHub Pages
1. یک Repository جدید در GitHub بسازید.
2. تمام فایل‌ها و پوشه‌های این پروژه را در ریشه Repository بارگذاری کنید.
3. وارد `Settings → Pages` شوید.
4. در بخش **Build and deployment** گزینه **Deploy from a branch** را انتخاب کنید.
5. شاخه `main` و پوشه `/(root)` را انتخاب و Save کنید.
6. پس از چند دقیقه آدرس نمایش سایت در همان بخش ظاهر می‌شود.

## شخصی‌سازی قبل از انتشار
- آدرس ایمیل `info@rezapudineh.ir` را در صورت نیاز با ایمیل قطعی جایگزین کنید.
- اطلاعات خدمات، آمار و متن معرفی را با داده‌های تأییدشده صاحب کسب‌وکار هماهنگ کنید.
- لینک شبکه‌های اجتماعی و نمونه‌کارهای واقعی را در صورت موجود بودن به فوتر و بخش نمونه‌کارها اضافه کنید.
- فونت Vazirmatn از Google Fonts بارگیری می‌شود؛ برای میزبانی کاملاً مستقل می‌توانید فایل فونت را در پروژه قرار دهید.

## ویژگی‌ها
- طراحی RTL و فارسی
- واکنش‌گرا برای موبایل، تبلت و دسکتاپ
- منوی موبایل
- اسکرول نرم و انیمیشن ورود بخش‌ها
- شمارنده‌های متحرک
- پشتیبانی از `prefers-reduced-motion`
- بدون کتابخانه JavaScript خارجی
- متادیتای پایه و favicon اختصاصی

> توجه: این پروژه یک قالب نمایشی است. فرم ارسال اطلاعات یا پنل مدیریت ندارد و اطلاعات نمونه مانند آمار باید پیش از انتشار نهایی بررسی شوند.
